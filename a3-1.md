# Activity 3 – Step 1: Ask for structured output

**Chatbot / model:** <!-- e.g., ChatGPT (GPT-5), Gemini, Claude / เช่น ChatGPT (GPT-5), Gemini, Claude -->

## Prompt

```text
Create a JSON object with random data for a hotel guest that contains the following fields: fullname (string), age (integer), vip (boolean), email (string), favouriteRooms (array of integers), and an object called address that contains street, city and postcode.
```

## Response

```json
{
  "fullname": "Oliver Bennett",
  "age": 34,
  "vip": true,
  "email": "oliver.bennett@example.com",
  "favouriteRooms": [102, 205, 310],
  "address": {
    "street": "42 Maple Avenue",
    "city": "London",
    "postcode": "SW1A 1AA"
  }
}
```
